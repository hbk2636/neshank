# فاز ۰ — ابزار «دانلود ویدیو» (بخش ابزارها): کاوش، تصمیم‌ها و برنامه

تاریخ: ۲۰۲۶/۰۹/۲۹ — نسخهٔ سند: ۱ — وضعیت: در انتظار تأیید کاربر (پیاده‌سازی تا تأیید شروع نمی‌شود)

## ۱) محدودیت توزیع — مبنا و مرز همهٔ تصمیم‌ها

روش کار مشخص است: کاربر DMG را نصب می‌کند و **همه‌چیز بدون هیچ تنظیمی** باید کار کند؛
سرور/VPS وجود ندارد؛ برنامه رایگان روی گیت‌هاب منتشر می‌شود. پس:

| گزینه | حکم | دلیل |
|---|---|---|
| **yt-dlp باندل‌شده داخل `.app`** | ✅ **انتخاب** | باینری مستقل مک (بدون نیاز به Python)، در مرحلهٔ build روی مکِ سازنده دانلود و باندل می‌شود؛ صفر تنظیم برای کاربر؛ رایگان |
| cobalt (self-host یا سرور) | ❌ رد | به سرور/Docker نیاز دارد — با مدل توزیع نمی‌سازد |
| پروایدرهای API (Video-Download-API و مانند آن) | ❌ رد (فعلاً) | پرداخت/کلید/وابستگی به سرویس ثالث؛ ناسازگار با «رایگان و خودکفا» |
| youtubei.js داخل WKWebView | ⏸ ذخیره به‌عنوان جایگزین آینده | رایگان و بدون باینری، اما ریسک PO Token برای ویدیو و نگهداری JS؛ اگر روزی yt-dlp در مک گیر افتاد، مسیر دوم است |

**یادداشت حقوقی:** دانلود از یوتیوب برخلاف شرایط استفادهٔ آن است (به‌جز محتوای خود کاربر و مجوزهای آزاد). مسئولیت استفاده با کاربر است؛ در صفحهٔ آموزش یک یادداشت کوتاه می‌آید.

## ۲) کاوش مخزن

| مورد | نتیجهٔ کاوش |
|---|---|
| الگوی ابزار | دقیقاً الگوی «طراحی نقشه ذهنی»: ردیف در `Section("ابزارها")` سایدبار → پنجرهٔ نیتیو مستقل (۱۰۰۰×۷۲۰، حداقل ۷۶۰×۵۶۰، ⌘W) → ماشین حالت (`MindMapToolModel` الگو) → `NSWindow` با تیتربار استاندارد و هماهنگی تم/RTL |
| اجرای پروسهٔ جانبی | `Process` استاندارد فاندیشن — پیش‌نیاز جدیدی ندارد. باینری yt-dlp داخل `Contents/MacOS/` باندل و در همان اسکریپت build با `codesign` امضای ad-hoc می‌گیرد |
| باندل در build | `Scripts/build_app.sh` الگوی آماده دارد (MindElixir/Readability همان‌جا باندل می‌شوند) — yt-dlp هم با نسخهٔ پین‌شده و بررسی SHA256 دانلود و کپی می‌شود |
| آپدیت yt-dlp | باندلِ داخل `.app` فقط‌خواندنی است (`/Applications`) → نسخهٔ جدید در `~/Library/Application Support/NeshankYar/tools/` نوشته می‌شود؛ لودر همیشه نسخهٔ App Support را بر باندل ترجیح می‌دهد. چک نسخه از API ریلیزهای گیت‌هاب yt-dlp |
| نشان کتاب YouTube | نشانک‌هایی که دامنه‌شان youtube/youtu.be است در پنجرهٔ ابزار به‌عنوان «ویدیوی آمادهٔ دانلود» شناخته می‌شوند؛ پر کردن خودکار URL از نشانک انتخاب‌شده |
| ترنسکریپت برای آرشیو | yt-dlp زیرنویس خودکار می‌دهد (`--write-auto-subs --sub-lang fa,en --sub-format srt/vtt`)؛ پارس SRT/VTT به متن ساده = ستون محتوای نشانک → جستجوی عمیق و دستیار روی ویدیو کار می‌کند |
| متادیتا | `--dump-single-json` → عنوان، کانال، مدت، بندانگشتی، توضیحات — پر کردن نشانک بدون باز شدن صفحه |
| پیشرفت دانلود | `--newline --progress` → خطوط `[download] ۴۲.۳%` پارس می‌شود؛ همان نقش چک‌لیست ۵ مرحله‌ای نقشهٔ ذهنی |
| تست | پارس JSON/پیشرفت با fixture آفلاین (بدون شبکه) + تست زندهٔ دانلود واقعی روی ۳ ویدیو (کوتاه، بلند، فارسی) به‌صورت دستی در فاز ۱ |

## ۳) تصمیم‌های ثبت‌شده (پیش‌نویس — پس از تأیید قطعی می‌شوند)

1. بک‌اند: yt-dlp باندل‌شده؛ پروایدر API و cobalt از فاز ۰ حذف (با امکان افزودن به‌عنوان Backend دوم در آینده — لایهٔ Backend از روز اول انتزاعی می‌ماند).
2. فاز ۱ فقط **صدا (M4A) و ویدیوی تا ۷۲۰p**: این قالب‌ها «پیش‌مکس»اند و به ffmpeg نیاز ندارند → برنامه سبک و بدون وابستگی دوم می‌ماند.
3. مقصد فایل: پیش‌فرض `~/Downloads/نشانکیار/` + انتخابگر پوشه در پنجرهٔ ابزار.
4. نام فایل‌ها از قالب yt-dlp با حذف نویسه‌های غیرمجاز مک؛ نام فارسی پشتیبانی می‌شود (گیت RTL).
5. آپدیت‌ر yt-dlp از فاز ۳ (قبل از آن، آپدیت با نسخهٔ جدید DMG پوشش داده می‌شود).
6. رابط کاربری پنجره: فیلد/انتخاب URL → انتخاب خروجی (MP3 / MP4 ۷۲۰p) → نوار پیشرفت → محل ذخیره؛ دکمهٔ «افزودن به کتابخانه» برای ساخت نشانک ویدیویی از همان دانلود.

## ۵) گیت‌های اجباری (روز اول)

- **گیت RTL:** نام فایل فارسی، متن فارسی در رابط، عدم شکستن متن دکمه‌ها در پنجرهٔ باریک، چیدمان فرم در RTL.
- **گیت حجم:** DMG از ~۲.۵MB به ~۴۰MB می‌رسد (باینری yt-dlp) — پذیرفته شد به‌شرط دانلود موفق روی مک بدون Python/ffmpeg.
- **گیت خودکفایی:** روی یک مک تمیز (بدون brew/Python/ffmpeg) دانلود MP3 و MP4 ۷۲۰p باید بدون هیچ پیام خطایی کار کند.

## ۷) سؤالات باز — نیازمند تصمیم کاربر

1. نام نمایشی ابزار: «دانلود ویدیو» یا «ویدیو یوتیوب»؟
2. مقصد پیش‌فرض فایل‌ها: `~/Downloads/نشانکیار/` تأیید می‌شود؟
3. آیا از فاز ۱ نشانک ویدیویی خودکار ساخته شود (بعد از هر دانلود، پرسش «افزودن به کتابخانه؟») یا دکمهٔ دستی باشد؟
