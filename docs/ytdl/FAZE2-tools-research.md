## ۱) گزینه‌های بررسی‌شده (مستند، نه حدس)

|---|---|---|---|
| **yt-dlp** (آخرین پایدار `2026.08.19`، نایتلی `2026.09.27`) | فعال؛ همین ماه کلاینت `visionos` و فالبک `web_embedded` اضافه شد | ✅ **موتور اصلی — نگه داشته شود** | به‌روزترین، همهٔ فالبک‌ها را خودش مدیریت می‌کند؛ باینری مستقل مک بدون Python |

| **کوکی مرورگر کاربر** (`--cookies` / `--cookies-from-browser`) | قابلیت داخلی yt-dlp، بدون وابستگی | ✅ **مسیر مطمئن امروز** | UI آن در برنامه ساخته شده؛ در برابر bot-check پایدارترین است |

نکتهٔ فنی از راهنمای رسمی: کلاینت `web_safari` فرمت‌های HLS می‌دهد که فعلاً PO Token نمی‌خواهند،
و yt-dlp خودش بین کلاینت‌ها فالبک می‌زند — پس **دست‌کاری `player-client` در کد لازم نیست**؛
پیش‌فرض‌های آپ‌استریم از انتخاب دستی ما بهتر نگهداری می‌شوند.
